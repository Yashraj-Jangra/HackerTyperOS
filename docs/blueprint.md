# **App Name**: HackerTyper OS

## Core Features:

- File Manager Illusion: Fake file manager with interactable directories and 'files' filled with lorem ipsum or sarcastic error messages when 'executed'.
- Sarcastic Hack Tools: Dummy 'hacking tools' like 'hack.exe', 'DDoS script', or 'Nethunter' that display a sequence of fake hacking outputs upon execution, culminating in a funny message (e.g., 'Target successfully annoyed!').
- Parody Task Manager: A task manager that shows fake CPU and GPU stats with humorous labels (e.g., 'CPU: Running Memes,' 'GPU: Rendering Cat Videos') and processes with names like 'WindowsUpdate.exe' (always at 99% CPU) or 'ImportantBackgroundProcess.exe'.
- Interactable CMD: Simulate a command-line interface with interactable commands that produce humorous or nonsensical outputs.
- System Info: Display fake system information with sarcastic details (e.g., 'OS: Definitely Not Windows,' 'RAM: Downloaded from the Internet').
- Widgets: Include widgets displaying 'important' system metrics, fake error logs, and humorous notifications.
- Context Menu Shenanigans: Include a right-click context menu with useless options like “Hack this file” or “Send to Narnia,” each triggering a humorous animation or message.
- Glitch Effects: Add random visual glitches (e.g., screen flickering, distorted text) to sell the “broken system” vibe, with messages like, “Glitch detected: Reality unstable.”

## Style Guidelines:

- Primary color: Dark green (#00FF00) to mimic classic hacking interfaces.
- Secondary color: Dark gray (#333333) for backgrounds and panels.
- Accent: Bright cyan (#00FFFF) for highlighting interactive elements and error messages.
- Use a tiled window layout to resemble a busy, multi-window hacking environment.
- Icons should be reminiscent of early 2000s operating systems, blocky and simple.
- Text should scroll and animate in a fast, chaotic manner to simulate rapid hacking. Implement a matrix-like theme where applicable.
